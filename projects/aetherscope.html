Aetherscope

Aetherscope is a real-time fractal visualization tool written in C. It allows users to visualize and analyze fractals in a visually appealing way.

Overview

This project explores data visualization techniques, performance, and C programming concepts.

Why I made it

I wanted to learn more about how data visualization works and improve my C skills.

Technologies
