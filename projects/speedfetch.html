Speedfetch

Speedfetch is a system information fetcher written in Rust. It displays system information in a visually appealing way.

Overview

This project explores system information fetching, performance, and Rust programming concepts.

Why I made it

I wanted to learn more about how system information fetching works and improve my Rust skills.
