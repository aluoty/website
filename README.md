# Website

Personal portfolio site of me built with HTML, CSS and some JS.
[An official mirror](https://aluoty.github.io/website/) of my website is hosted on Github pages.

Install the `npm` dependencies if you want to test the code via `npm install`.

## Commands

+ Build HTML articles from MarkDown articles by running `npm run build` or `node build.js`
+ Run the site dynamically via `vite` by running `npm run dev` or `vite --open`
+ Run the site alternatively by opening the `index.html` file
